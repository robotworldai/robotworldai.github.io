RobotWorld

Benchmarking Multimodal Agents for Robot Use
Across Diverse Tasks and Embodiments

同一个多模态 agent，只通过公开的观测与动作工具，控制机械臂、灵巧手、人形、四足、小车和无人机，在仿真中完成任务并由环境私有评分器打分。

01 / Overview

模型怎样“用”机器人

每道题把机器人暴露为一组工具。模型看图像与状态，决定动作，环境执行后返回回执与新观测；是否完成任务由模型看不到的评分状态判定。

  1. 观测相机图像、关节与任务状态，只给许可信息
  2. 决策多模态 agent 推理，可调用辅助工具分析
  3. 动作通过各环境动作工具下发，按控制步执行
  4. 反馈执行回执、新观测与剩余预算
  5. 私有评分原 checker 或 world-state-v1，不对模型公开

05 / Protocol

评测口径

两种步数

仿真控制步是环境实际执行的物理控制步，受每题预算限制；轨迹记录序号是日志中的事件编号，二者不同。

动作预算

沿用原题预算；BEHAVIOR 用 min(官方, 2000)；16 项重新设计的场景使用已批准时长与 world-state-v1 判定。

结束原因

达到控制步上限、环境原生终止、world-state 终止分别标注。不向模型提供放弃工具；模型结束回答但环境仍在运行时，会提醒它继续。基础设施中断不计分，不算 0 分。

非动作预算

现行规则：连续 15 次交互没有执行控制步，或累计达到每题上限 30／60／120 次（RoboDojo 为 30），即停止并记 0 分。部分早期结果使用其他上限或没有上限，以每次尝试记录的协议为准。

恢复

API 断流与偶发图片处理拒绝，保留同一仿真与会话，退避 10/20/40 秒原地恢复，最多 3 次，不重放已完成动作。

覆盖

每模型 84 题，覆盖五大领域。各题展示实际结果、录像与协议；未完成记录仍为未计分。
